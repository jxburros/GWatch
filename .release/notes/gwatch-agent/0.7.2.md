# GWatch Agent 0.7.2

The first published release since 0.6.x. 0.7.0 and 0.7.1 were never published, so
their notes follow and everything in them ships in this release.

## Changed

- **Release publishing.** The shared release tooling is updated to a version that finds
  a newly created draft release in the release list; the 0.7.1 run stopped at that
  step before publishing anything. No change to GWatch Agent itself.
