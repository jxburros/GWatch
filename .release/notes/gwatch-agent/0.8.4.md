# GWatch Agent 0.8.4

GWatch 0.8.5 and GWatch Agent 0.8.4 ship together.

## Changed

- **Rebuilt with GWatch 0.8.5's shared code.** The agent has no changes of its own.
  The code it shares with GWatch gained node colours and the *Pings per check*
  setting; as a remote collector the agent sends, for each ping check, the number
  of pings GWatch hands it, so a check that follows the setting is run the same
  way from a collector as from GWatch itself.
