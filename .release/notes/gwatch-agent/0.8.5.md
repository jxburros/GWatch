# GWatch Agent 0.8.5

GWatch 0.8.6 and GWatch Agent 0.8.5 ship together.

## Changed

- **Rebuilt by the updated release workflow.** The agent has no changes of its own.
  The build and signing jobs no longer refuse to run until the release commit is
  already on `main`, and the GitHub Actions the workflows run on are updated
  (`actions/setup-node` 7, `docker/setup-buildx-action` 4,
  `docker/setup-qemu-action` 4, `docker/build-push-action` 7 and
  `docker/login-action` 4).
