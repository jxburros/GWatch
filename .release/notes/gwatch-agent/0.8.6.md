# GWatch Agent 0.8.6

GWatch 0.8.8 and GWatch Agent 0.8.6 ship together.

## Added

- **Watch all running containers at once.** Once the control panel has listed
  what the machine has, *Containers to watch* and *Virtual machines to watch*
  have a *Watch all running* button that adds every running one to the list.

## Changed

- **Rebuilt with the code it shares with GWatch.** GWatch 0.8.8 adds the
  network map's hand arrangement to the configuration model the two share.
