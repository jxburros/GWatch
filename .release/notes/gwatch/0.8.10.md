# GWatch 0.8.10

GWatch 0.8.10 and gwatch-agent 0.8.7 ship together. One security fix, and the
documentation reorganised around the person using GWatch. If you have handed
out a read-write API key (the MCP companion's included), update.

## Security

- **A request GWatch makes to itself is no longer the local administrator.** A
  client on the computer GWatch runs on is the administrator with no sign-in,
  unless **Require sign-in on this computer too** is on. An HTTP check, a
  webhook action or a Matter server address aimed at GWatch's own port arrived
  over loopback and was given that same access, so a read-write API key, which
  may create and test HTTP checks, could do anything an administrator can.
  GWatch now recognises the loopback connections it opens itself and makes
  them carry a credential like any other client.

## Documentation

- The README is written for the person installing GWatch. Building, testing
  and releasing moved to `CONTRIBUTING.md` and `docs/development/`.
- New: `SECURITY.md`, `CONTRIBUTING.md`, issue templates and an index at
  `docs/README.md`.
- Corrections from an audit of every document against the code.
