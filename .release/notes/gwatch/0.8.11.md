# GWatch 0.8.11

GWatch only; gwatch-agent stays at 0.8.7. No change to the program: this
release adds the project's governance documents and rebuilds the roadmap. It
also carries everything in 0.8.10, which was not published on its own,
including a security fix for anyone who has handed out a read-write API key.

## Documentation

- **Governance documents for contributors and AI coding agents.** `AGENTS.md`
  and `development-docs/` set out what GWatch is and must not become, how it
  is developed and what counts as done, its current architecture, and the
  roadmap.
- **The roadmap moved** from `ROADMAP.md` to
  `development-docs/productRoadmap.md`, rebuilt around every open issue. The
  old `ROADMAP.md`, with the original public-release plan (all shipped), is
  archived in `development-docs/architecture-plans/archives/`.
