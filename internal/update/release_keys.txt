# GWatch release signing keys (pinned into the binary).
#
# One trusted ed25519 public key per line:
#
#   ed25519:<base64 of the 32-byte public key>
#
# Lines starting with # and blank lines are ignored. Several keys may be listed
# at once so a key can be rotated: a release signed by any listed key is
# accepted, which lets a new key be added here and shipped in a release before
# the old one is retired.
#
# A build with no key here refuses to install updates ("this build has no
# release signing key"). To add one, run:
#
#   go run ./cmd/gwatch-sign keygen -out release.key
#
# then paste the printed "ed25519:..." line below this comment, keep
# release.key offline, and store its base64 seed as the GWATCH_SIGNING_KEY
# repository secret. See docs/RELEASING.md.
#
# A fork that signs with its own key can instead override this list at build
# time, without editing the file:
#
#   go build -ldflags "-X github.com/jxburros/GWatch/internal/update.releaseKeys=ed25519:AAAA..." .
