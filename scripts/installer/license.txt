PRIVACY

  * GWatch is local-first and self-hosted. JX Holdings, LLC operates no
    server, receives nothing, and could not read your data if asked.
  * There is no telemetry, no analytics, no crash reporting and no
    account. The interface loads nothing from the internet.
  * Everything is kept in an embedded SQLite database in the data
    directory (on Windows, C:\ProgramData\GWatch): checks and history,
    hardware readings, incidents, the audit log, accounts, and settings.
    Passwords, session tokens, API keys and agent tokens are stored only
    as hashes; the SMTP, access and backup passwords are encrypted with
    a key file kept beside the database.
  * The only outbound traffic is the checks you configure, email through
    your own SMTP server, update checks to GitHub when you press Check
    for updates, notifications to endpoints you set up, and readings the
    optional agent pushes to your own GWatch server.
  * You are the data controller for everything GWatch records, including
    any of it that counts as personal data where you live.

SECURITY DISCLAIMER

  * GWatch has no password by default and speaks plain HTTP. That is
    safe on 127.0.0.1 and not safe anywhere else.
  * Allowing other devices on your network exposes everything GWatch can
    do to every device on that network until you create an account.
  * Never forward GWatch's port from your router to the internet. For
    remote access use a private network (Tailscale, WireGuard) or a
    reverse proxy with TLS.
  * Weak or reused passwords, disabled sign-in, shared read-write API
    keys, endpoint tokens and agent tokens on machines you do not
    control are all your risk to take.
  * Stored SMTP and backup passwords are only as safe as this machine
    and the permissions on the data directory.
  * These are your choices to make in your own environment. JX Holdings,
    LLC is not liable for their consequences.
  * Recommended baseline: set a password, keep GWatch on your LAN, use a
    reverse proxy with TLS for remote access, restrict the data
    directory, give each token one job, and keep GWatch updated.
